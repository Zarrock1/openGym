# openGym на своём сервере (VPS + домен + HTTPS)

Сайт на твоём домене: заходишь, входишь в свой профиль и пользуешься приложением.
На iPhone его можно добавить на экран «Домой», и оно будет работать как обычное
приложение: на весь экран, офлайн, с уведомлениями. App Store не нужен.

Что получится:

```
iPhone (Safari) ── HTTPS ──▶ Caddy :443 ──▶ web (nginx + приложение) ──▶ api (данные в ./data)
```

Caddy сам получает и продлевает сертификат Let's Encrypt.

## Что нужно

- VPS с Linux (хватит 1 ГБ RAM), на котором свободны порты 80 и 443.
- Домен или поддомен, например `gym.example.com`. Подойдёт и бесплатный (duckdns.org, desec.io).
- В DNS у домена A-запись, указывающая на IP сервера (если есть IPv6, ещё и AAAA).

HTTPS и настоящий домен обязательны: вход по passkey (Face ID / Touch ID) браузеры
разрешают только так.

## Установка

```bash
# 1. Docker (если его ещё нет)
curl -fsSL https://get.docker.com | sh

# 2. Код
git clone https://github.com/DuarteSantos8/openGym.git
cd openGym

# 3. Запуск: создаёт .env, скачивает готовые образы, поднимает api + web + caddy
sh deploy/vps/setup.sh gym.example.com
```

Через минуту открой `https://gym.example.com`.

## Первый вход и «личный кабинет»

1. В Safari на iPhone открой свой домен и нажми **Создать профиль**. Придумай имя,
   подтверди через Face ID: создастся passkey, пароль не нужен.
2. Первый созданный профиль становится **админом**: в настройках появится «Admin dashboard»
   (пользователи, коды приглашений, журнал входов).
3. **Поделиться → На экран «Домой»**. Теперь openGym открывается с иконки как приложение.
4. Закрой сервер от чужих: раскомментируй в `.env` две строки
   ```
   INVITE_ONLY=1   # новый профиль только по коду приглашения из админки
   ALLOW_GUEST=0   # убрать кнопку «Продолжить без аккаунта»
   ```
   и перезапусти:
   ```bash
   docker compose -f docker-compose.yml -f deploy/vps/docker-compose.caddy.yml up -d
   ```
   Друзьям выдавай коды приглашения из админки. У каждого будет свой профиль со своими данными.

Если войти по passkey нельзя (другое устройство, потерянный ключ), в `.env` можно включить
`PASSWORD_LOGIN=1`. Тогда профиль можно будет защитить ещё и паролем (см. `docs/SELF_HOSTING.md`).

## Обслуживание

```bash
C="docker compose -f docker-compose.yml -f deploy/vps/docker-compose.caddy.yml"

$C pull && $C up -d          # обновиться до новой версии
$C logs -f caddy             # если не выдаётся сертификат (DNS, закрыт порт 80)
$C logs -f api               # ошибки бэкенда
tar czf opengym-backup-$(date +%F).tar.gz data/   # бэкап: всё хранится в ./data
```

## Если на сервере уже есть nginx / Caddy / Traefik

Тогда этот оверлей не нужен, порты 80/443 уже заняты. Запусти обычный стек
(`docker compose up -d`), в `.env` укажи `RP_ID`/`ORIGIN` своего домена и
`WEB_PORT=127.0.0.1:8080`, а в своём прокси направь домен на `http://127.0.0.1:8080`.
Подробнее в `docs/SELF_HOSTING.md`.
